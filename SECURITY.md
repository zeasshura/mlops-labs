# Проверка публикации

Перед переносом отбирались только файлы, отслеживаемые в закреплённых снимках исходных репозиториев. У каждого экспортированного файла сверены Git blob SHA и SHA-256. Локальные незакоммиченные файлы не переносились.

Исключены вложенные .git, среды, ключевые файлы, .env, .aws/.ssh, веса, тензоры, датасеты, DVC-кэши, volumes, логи, видео, сборочные бинарники и файлы больше 5 MiB. DVC-указатели сохранены. Истории старых репозиториев не импортированы: они уже содержат тяжёлые артефакты.

Отобранные файлы, включая содержимое XLSX, проверяются официальным Gitleaks 8.30.1. Бинарник получен из официального GitHub release, SHA-256 архива сверен с опубликованными checksums. Используются встроенные правила без проектных allowlists; inline-комментарии gitleaks:allow не учитываются. Результат дополнительно проверяется по точному Git-снимку перед отправкой. Секретные значения в выводе сканера скрываются.

Первичная проверка обнаружила четыре ложных совпадения в автоматически составленном манифесте: SHA-256 содержимого рядом с именами файлов, содержащими token. Подтверждено, что это хеши файлов, а не ключи. Изменён только формат манифеста; правила сканера не ослаблены.

Учебный пароль PostgreSQL classroom-local из выданного compose-конфига оставлен как локальный демонстрационный параметр. Он не используется для GitHub, облачных сервисов или внешней базы. GitHub-токен из gh/keyring не читался и не копировался в файлы.

## Повторная проверка

Установите Gitleaks из https://github.com/gitleaks/gitleaks/releases (версия переноса: 8.30.1), затем:

```bash
python3 scripts/check_publish.py
```

Локальный pre-commit hook проверяет staged-снимок, блокирует артефакты и запускает Gitleaks. Если сканер отсутствует, commit блокируется. `git add -f` не обходит проверку содержимого hook.

Автоматический поиск снижает риск случайной публикации ключей, но не является доказательством отсутствия любых возможных секретов. При обнаружении настоящего ключа публикацию нужно остановить, а ключ отозвать у соответствующего сервиса. Старые публичные истории этим переносом не очищаются и не выдаются за проверенные целиком.
