Исходный прототип сохранён коммитом `f40eae0`. Подробная таблица: `../defects.csv`.
Публичный `tests/test_release.py` сохранён побайтно; тесты ДЗ 6–7 не редактировались.

| № | Причина | Исправление | Новая проверка |
|---|---|---|---|
| 1 | Кеш зависел от имени файла | SHA-256 байтов + канонический JSON всех настроек | `test_01`, `test_02` |
| 2 | Проверялась только truthiness поля passed | Полный контракт, настоящий bool, конечные метрики, версия/runtime/хеши | `test_03` |
| 3 | Указатель записывался поверх старого | Временный файл рядом, flush/fsync, os.replace, очистка | `test_04` |
| 4 | Каждая попытка добавляла событие публикации | Release ID из manifest+report, уникальный журнал и восстанавливаемый intent | `test_05`, `RecoveryTests` |
| 5 | ready был True до прогрева | Готовность только после загрузки и warmup | `test_06` |
| 6 | Ответ рекламировал указатель вместо модели в памяти | ID и runtime берутся из загруженного backend | `test_07` |
| 7 | Неверный запрос запускал генератор | Строгая проверка до очереди и вызова backend | `test_08` |

Восемь новых интеграционных тестов находятся в `tests_integration/test_incidents.py`.
Три из них обращаются к настоящему HTTP-серверу; subprocess-проверки пересекают границы процессов.
На исходном прототипе все восемь падают по проверяемым свойствам. Лог: `evidence/before.txt`.
На исправленной версии тот же набор выполняется со stdlib-адаптером и FastAPI:
`evidence/after-stdlib.txt`, `evidence/after-fastapi.txt`. Общий diff: `evidence/fixes.diff`.
Ошибки импорта/неизвестной команды не используются как доказательство исходных семи причин.

Отдельно проверяются: подмена файлов артефакта, смена evaluation_run_id,
сбой после обновления accepted.json до записи журнала и повторное восстановление.
Для диска используются mock-ошибки, настоящий диск не заполняется.

## Исправления окружения при выполнении

- Prefect 3.6.6 оказался несовместим с новой маршрутизацией FastAPI 0.142.2.
  Закреплены FastAPI 0.118.3 и Starlette 0.48.0 в lock-файле; flow и HTTP перепроверены.
- Перед чтением `mlflow-artifacts:` явно устанавливается HTTP tracking URI.
- Для существующих MLflow volumes используется исходное имя Compose-проекта `mlops-hw6`.
  Пустой временный проект остановлен, исходные volumes не удалялись.
- Loopback HTTP-тесты обходят proxy окружения, иначе proxy мог возвращать посторонний 503.
- Prefect использует локальное постоянное result storage; не передаётся незарегистрированный block.

Эти проблемы окружения перечислены отдельно и не увеличивают число семи дефектов прототипа.
