# MLOps · ДЗ 3: ответы по абзацам Википедии

Этот проект строит chat-датасет для кратких ответов на вопросы по данному абзацу. Основа — [SQuAD 1.1](https://rajpurkar.github.io/SQuAD-explorer/). Каждая строка содержит проверенный фрагмент ответа, исходный абзац и вопрос. Пайплайн очищает строки, проверяет разнообразие, делит по целым статьям и проверяет пересечения между train, val и test.

Тема для согласования с преподавателем: **извлечение ответов из англоязычных абзацев Википедии**.

## Запуск

Нужны Python 3.12+ и `uv`.

```bash
uv sync
make source  # скачает два официальных JSON, проверит SHA-256 и добавит в DVC
make v1      # 60 статей из train → 13 168 очищенных примеров
make v2      # 60 статей train + 30 статей dev → 19 387 примеров
make check   # восемь блоков самопроверки
```

Текущая рабочая версия — `v2`. `make repro` повторяет пайплайн для версии из `params.yaml`; `make dag` показывает граф DVC, `make diversity` и `make contamination` запускают отдельные гейты. Исходные JSON и готовые JSONL исключены из git и отслеживаются DVC. Локальный remote настроен в `.dvc/config`; `uv run dvc push` сохраняет текущие объекты в `dvc_remote/`. На новой машине достаточно `make source` и `make v2`, даже если локальный remote пуст.

Версии задаются в `params.yaml` и сохраняются в `dvc.lock`. После фиксации двух состояний проекта в истории `make diff` показывает разницу метрик через `dvc metrics diff`. Точные числа обеих версий, ограничения и правила использования указаны в [паспорте](docs/datasheet.md); пять проверенных дефектов — в [отчёте](docs/defects.md).
