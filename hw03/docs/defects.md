# Пять дефектов пайплайна и их проверки

## 1. Файлы данных могли попасть в git

Без игнорирования `data/` и исходных JSON команда `git add .` добавила бы крупные файлы в историю. `data/`, локальные cache и remote DVC исключены из git; два официальных JSON имеют `.dvc`-указатели, пять JSONL объявлены выходами `dvc.yaml`. `make check` подтверждает ноль отслеживаемых файлов в `data/`, а `dvc push` сохранил обе версии в локальном remote.

## 2. Смена версии не запускала бы сборку

Стадия `collect` должна зависеть от `collect.version`, лимитов статей и исходных JSON. Все параметры `collect` объявлены в `dvc.yaml`, оба источника — в `deps`. Контроль v1 → v2 меняет `raw.jsonl` с **13 250** до **19 511** строк и MD5 очищенного файла с `fd2b5dd2…` на `4b7442a7…`; `dvc.lock` фиксирует входы и выходы.

## 3. Случайный сплит отдельных вопросов загрязнил бы тест

У одной статьи есть много вопросов к разным абзацам. Раздача строк перемешала бы её контекст между train и test. Сплит распределяет целые статьи с seed `42` и затем проверяет все пары train/val/test. В `v2` получено **15 336 / 1 928 / 2 123** строк и **75 / 8 / 7** статей; во всех парах — ноль пересечений по ID, тексту вопроса, статье и near-dup.

## 4. Точная дедупликация пропускала бы близкие вопросы

Разный пробел перед знаком вопроса меняет нормализованную строку, но не её словные шинглы. Очистка сравнивает именно вопрос, исключая общий абзац статьи, ищет кандидатов MinHash/LSH и подтверждает их точным Жаккаром при `0.85`. На реальной `v2` удалены **68** точных повторов и **3** near-dup; контрольная пара из `make check` даёт по одному удалению каждого типа, а пара с Жаккаром `0,80` сохраняется.

## 5. Предупреждение о разнообразии не останавливало бы пайплайн

Гейт завершает стадию ошибкой при нарушении любого порога и печатает фактическое значение. Контрольный набор из **1 200** однотипных примеров нарушает четыре порога и отклоняется. `v2` проходит: **19 387** строк, **5** системных промптов, **90** статей, максимум **4,07%** у одной статьи, разброс длин ответа **10,75**; доля повторяющихся ответов **20,40%** при пороге **30%**.
