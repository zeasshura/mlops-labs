# Перенос в общий репозиторий

Перенесены снимки шести работ в hw01, hw02, hw03, hw04, hw05 и hw06-07. Исходные локальные папки не менялись; их веса, данные и окружения сохранены на месте.

История нового репозитория начата заново. Исходные истории и сдачи остаются в старых репозиториях; они архивируются только после успешной публикации и проверки нового репозитория.

Изменения при переносе:

- Данные, модели, окружения, кэши, логи, видео и бинарник Compose исключены.
- Небольшие JSON-отчёты из metrics перенесены в reports; численные результаты не пересчитывались и не редактировались.
- Скрипты ДЗ 6–7, использующие исходные данные ДЗ 4, обращаются к соседней hw04.
- DVC remotes ДЗ 3 и 6–7 заменены на read-only HTTPS URL закреплённых старых коммитов.
- Исходники src, params.yaml и выданные tests сохранены побайтово. Поэтому сохранённые хеши кода/конфига в отчётах не меняются от переименования папок.
- Игнорирование и hook защищают будущие commits. Новый корневой README не создавался по просьбе владельца.

Исторические абсолютные пути, MLflow localhost URI и ссылки в старых отчётах описывают исходные прогоны; это не новые публичные адреса. Для работы с сохранёнными измерениями восстановите локальные артефакты. Окружения uv создаются отдельно внутри каждой работы.
